# miniRT

## Description

This project is an introduction to the world of Raytracing. The goal is to create a simple raytracer that can render simple objects, such as spheres and planes, cylinders,with basic lighting and shadows.

## Features

- Rendering spheres , planes and cylinders and cones
- Multiple light sources
- Shadows
- textures
